# koishi-plugin-streetfighter6-rank

[![npm](https://img.shields.io/npm/v/koishi-plugin-streetfighter6-rank?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-streetfighter6-rank)

一个用于查询《街头霸王 6》玩家数据的 Koishi 插件，支持排位查询、胜率分析、战斗记录截图和玩家搜索功能。

## 功能特色
- 🎮 排位查询：查看玩家当前排位、LP 值与角色使用情况
- 📊 胜率分析：详细胜率统计，包括各角色胜率数据
- 📸 战斗记录：自动截图展示最近战斗记录
- 🔗 绑定 ID：用户绑定自己的玩家 ID，便捷查询个人数据
- 🔍 玩家搜索：根据玩家名称搜索并获取基本信息
- ⚡ 智能缓存：内置缓存系统，提升查询响应速度
- 🌐 多语言支持：支持简体中文、繁體中文、English、日本語、한국어

## 安装
在 Koishi 控制台的插件市场中搜索 `streetfighter6-rank` 进行安装。

## 配置
### 网站连接配置
- 基础地址：Buckler 网站基础地址
  - 默认：https://www.streetfighter.com/6/buckler
  - 一般不需要修改，除非官方变更
- 页面语言：查询页面使用的语言
  - 选项：简体中文、繁體中文、English、日本語、한국어
  - 默认：简体中文。影响返回数据的语言显示
- 浏览器标识：模拟浏览器的 User-Agent
  - 默认：Chrome 124 Windows 标识
  - 用于避免被网站识别为机器人访问
- Cookie：手动设置的登录 Cookie
  - 如配置了自动登录则优先使用自动登录
  - 获取方式见下方"Cookie 获取方法"

### 自动登录配置 ⭐
- CAPCOM ID 邮箱：配置后将自动登录获取Cookie
  - 推荐使用此方式，无需手动获取Cookie
- CAPCOM ID 密码：配合邮箱使用自动登录
- 自动刷新 Cookie 的时间间隔（小时）：设置定时自动刷新 Cookie 的周期。默认为 0，即禁用。

### 功能开关
- 启用文本信息输出
  - 默认：开启。关闭后仅显示截图
- 启用截图输出
  - 默认：开启。关闭后仅显示文字
- 启用合并转发消息（玩家搜索结果）
  - 默认：关闭。开启后多个搜索结果将合并转发（QQ/OneBot 支持）

### 调试选项
- 输出详细调试日志
  - 默认：关闭。排查时建议开启

## 使用方法
### 推荐配置方法 ⭐
在插件配置中设置你的 CAPCOM ID 邮箱和密码，再输入 SF6登录 指令，插件将自动登录并获取 Cookie（目前已支持输入指令时自动触发一次登录，但由于cookies过期时间不固定，建议增加自动刷新时间）。

### Cookie 获取方法（手动方式）
如不想使用自动登录，也可手动获取：
打开浏览器访问 Buckler，登录你的 Capcom 账号。
按 F12 打开开发者工具，点击 Network 标签并刷新。
复制任意请求的 Cookie 头完整内容。
在插件配置中设置 Cookie。

### 基本命令
| 命令 | 功能 | 用法示例 |
|------|------|----------|
| `排位查询` | 查询玩家排位信息 | `排位查询 1234567890` 或 `排位查询 @用户` |
| `玩家查询` | 查询玩家个人信息 | `玩家查询 1234567890` 或 `玩家查询 @用户` |
| `胜率查询` | 查询玩家胜率统计 | `胜率查询 1234567890` 或 `胜率查询 @用户` |
| `战斗记录` | 截图显示战斗记录 | `战斗记录 1234567890` 或 `战斗记录 @用户` |
| `玩家搜索` | 搜索玩家信息 | `玩家搜索 PlayerName` |
| `绑定ID` | 绑定玩家 ID 到用户 | `绑定ID 1234567890` |
| `解绑ID` | 解除玩家 ID 绑定 | `解绑ID` |

### 登录管理命令 ⭐
| 命令 | 功能 | 说明 |
|------|------|------|
| `SF6登录` | 触发一次手动登录获取Cookie | 需要先配置邮箱密码 |
| `SF6状态` | 检查当前登录状态 | 查看Cookie和配置状态 |
| `SF6清除` | 清除当前Cookie | 下次查询时将重新获取 |
