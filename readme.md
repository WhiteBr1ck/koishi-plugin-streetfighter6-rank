# koishi-plugin-streetfighter6-rank

[![npm](https://img.shields.io/npm/v/koishi-plugin-streetfighter6-rank?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-streetfighter6-rank)

一个用于查询《街头霸王 6》玩家数据的 Koishi 插件，支持排位查询、胜率分析、战斗记录截图和玩家搜索功能。

## 功能特色
- 🎮 排位查询：查看玩家当前排位、LP 值与角色使用情况
- 📊 胜率分析：详细胜率统计，包括各角色胜率数据
- 📸 战斗记录：自动截图展示最近战斗记录
- 🔗 绑定 ID：用户绑定自己的玩家 ID，便捷查询个人数据
- 🔍 玩家搜索：根据玩家名称搜索并获取基本信息
- ⚡ 智能缓存：内置缓存系统，提升查询响应速度
- 🌐 多语言支持：支持简体中文、繁體中文、English、日本語、한국어

## 安装
在 Koishi 控制台的插件市场中搜索 `streetfighter6-rank` 进行安装。

## 配置
### 账号与 Cookie 配置
- Buckler 登录 Cookie
  - 最高优先级，也是当前推荐的登录方式
  - 必须复制已登录 Buckler 玩家页面请求中的完整 Cookie 请求头
  - 插件会在实际查询成功后将 Cookie 标记为已验证
- CAPCOM ID 邮箱和密码
  - 仅用于账号密码自动登录
  - 当前大概率被 Cloudflare 安全验证拦截，不推荐使用
- 账号密码自动登录 Cookie 刷新间隔
  - 默认：12 小时
  - 设置为 0 时不自动刷新
  - 仅对账号密码自动登录取得的 Cookie 生效

### 网站连接配置
- 基础地址：Buckler 网站基础地址
  - 默认：https://www.streetfighter.com/6/buckler
  - 一般不需要修改，除非官方变更
- 页面语言：查询页面使用的语言
  - 选项：简体中文、繁體中文、English、日本語、한국어
  - 默认：简体中文。影响返回数据的语言显示
- 浏览器标识：模拟浏览器的 User-Agent
  - 默认：Chrome 120 Windows 标识
  - 用于避免被网站识别为机器人访问

### 功能开关
- 启用文本信息输出
  - 默认：开启。关闭后仅显示截图
- 启用截图输出
  - 默认：开启。关闭后仅显示文字
- 启用合并转发消息（玩家搜索结果）
  - 默认：开启。开启后多个搜索结果将合并转发（QQ/OneBot 支持）

## 使用方法
### 推荐配置方法 ⭐
在普通浏览器中登录 Buckler，复制已登录玩家页面请求中的完整 Cookie 请求头，然后填写到插件的 `Buckler 登录cookies` 配置项。手动 Cookie 的优先级高于环境变量和账号密码自动登录。

CAPCOM ID 账号密码自动登录目前大概率被 Cloudflare 安全验证拦截，不应作为主要登录方式。

### Cookie 获取方法（手动方式）
1. 打开浏览器访问 Buckler，并登录你的 CAPCOM ID。
2. 打开一个能够正常显示数据的玩家资料页面。
3. 按 F12 打开开发者工具，进入 Network 标签并刷新页面。
4. 选择访问 `profile/玩家ID`、`play` 或 `battlelog` 的请求。
5. 在 Request Headers 中复制完整的 Cookie 请求头，不要只复制单个 Cookie 值。
6. 将完整内容填写到插件的 `Buckler 登录cookies` 配置项。
7. 重载插件后执行一次实际查询。查询成功后，`SF6状态` 会将 Cookie 显示为已验证。

### 基本命令
| 命令 | 功能 | 用法示例 |
|------|------|----------|
| `排位查询` | 查询玩家排位信息 | `排位查询 1234567890` 或 `排位查询 @用户` |
| `玩家查询` | 查询玩家个人信息 | `玩家查询 1234567890` 或 `玩家查询 @用户` |
| `胜率查询` | 查询玩家胜率统计 | `胜率查询 1234567890` 或 `胜率查询 @用户` |
| `战斗记录` | 截图显示战斗记录 | `战斗记录 1234567890` 或 `战斗记录 @用户` |
| `玩家搜索` | 搜索玩家信息 | `玩家搜索 PlayerName` |
| `绑定ID` | 绑定玩家 ID 到用户 | `绑定ID 1234567890` |
| `解绑ID` | 解除玩家 ID 绑定 | `解绑ID` |

### 登录管理命令 ⭐
| 命令 | 功能 | 说明 |
|------|------|------|
| `SF6登录` | 尝试账号密码自动登录 | 实验性功能，大概率被 Cloudflare 拦截 |
| `SF6状态` | 检查当前登录状态 | 查看 Cookie 来源、验证状态和自动登录状态 |
| `SF6清除` | 清除当前运行时 Cookie | 使用配置 Cookie 时需要重载插件才能重新读取 |
